# 扫描印刷稿套色偏移校准工具

用于校准扫描印刷稿套色（Registration）偏移的 Web 应用。上传参考图与扫描图，成对标注控制点，系统求出扫描图 → 参考图的六参数仿射变换，实时显示各点残差，叠加预览校准效果，并可导出矩阵与残差 JSON、以及校准后的扫描图 PNG。两图已加载且当前拟合矩阵可导出时，还可在「**差异区域**」视图中逐像素比较校准扫描图与参考图，按色差阈值生成差异掩码、八邻域连通分组并过滤小面积区域，按面积排序列出各区域边框、像素数与参考图坐标范围。差异区域支持**人工复核**：点击表格行或画布中的差异像素选中区域，标为「**缺陷**」或「**可接受**」并填写备注，表格展示结论；可导出含**参考图坐标范围、像素数、结论与备注**的 `diff-review.json`。色差阈值、最小面积或控制点引发重算时，以区域实际差异像素计算新旧区域交并比（IoU），**仅当 IoU ≥ 0.5 且双方互为唯一重叠区域时才继承结论**，其他新区域一律显示未复核，绝不按排序编号沿用；更换任一图片时清空全部复核记录。

整图仿射校准后，「**局部套色偏移**」视图帮助操作者定位仍有局部套色偏移的位置：复用差异视图与校准扫描图导出所用的**同一份校准重采样像素**，把参考图均匀分成 **4×4 共 16 块**，每块在块内**等距取样至多 1024 个整数像素**；在水平、垂直各 **±4 px 的整数位移**（共 81 个候选，含 (0,0)）内比较参考像素与位移后的校准像素，**仅计双方 alpha ≥ 128 的像素对**，度量其 **RGB 三通道平均绝对差**。候选的可比较点数**须不少于该块采样点数的 20%** 才参与选择；在合格候选中**取均差最小者，平局先取位移长度 sqrt(dx²+dy²) 较短者，再按 dx 升序、dy 升序**。界面按**参考图坐标**在各块上以**箭头标出最佳位移方向**（8 方向，屏幕坐标 y 向下；无偏移显示灰点），并列出各块的 **dx、dy、位移长度、位移前（0,0）均差与位移后均差**；**无合格候选的块（含空白/透明区域）显示「不可判定」**。图像或拟合矩阵变化后自动去抖重算，条件失效（缺图、控制点不足、共线拒绝、矩阵不可导出）时清空旧诊断；结果可导出 `local-shifts.json`。

拟合支持两种可切换的模式：

- **经典最小二乘**：全部控制点参与，最小化残差平方和（≥ 3 对）。
- **稳健模式（默认关闭，可随时开关）**：按**参考图像素容差**区分内点/外点。算法按固定顺序枚举有上限的非共线三点候选，以**内点数量优先、内点平方误差次之**选出最佳模型，再对全部内点重新最小二乘拟合并迭代至内点集合稳定。枚举上限保证计算量有界，点对增多时拖动不卡顿。外点在双图标记、残差表与导出文件中均单独标识，**不计入最终 RMSE**。

两种模式均附带**逐点留出验证**（leave-one-out）：对每个参与拟合的点，移除该点后用其余参与点重新做最小二乘仿射拟合，再预测留出点的参考图位置并计算误差。稳健模式的参与集为当前内点，外点显示「不参与」。参与点不足 4 个（留出后不足 3 个）或某次留出后的点集近共线时，对应点标记「**无法验证**」——绝不拿原拟合残差充数；汇总仅统计可验证点的 RMSE、最大误差与数量，零个可验证点时显示「不可用」。点位增删/拖动、模式与容差变化后，残差表的「留出验证」列与最差点提示实时更新。

- 后端：Node.js + Express（静态托管 + `/api/fit` 拟合接口）
- 前端：原生 Canvas（无任何前端框架/构建步骤）
- 拟合计算与 PNG 导出的像素重采样均在浏览器本地完成，图像不会上传服务器

## 快速开始

### 方式一：Docker（单条命令，含依赖安装与启动）

```bash
docker compose up --build
```

启动后在浏览器打开：**http://localhost:3000**

### 方式二：本地 Node.js（≥ 18）

```bash
npm install && npm start
```

### 访问地址

启动后在浏览器打开：**http://localhost:3000**（端口可通过环境变量 `PORT` 修改；Docker 端口映射同样为 `3000:3000`）

## 使用说明

1. **上传图像**：分别选择参考图与扫描图（或点击「载入示例图像」快速体验，示例内置已知偏移）。
2. **标注控制点**：在任意一幅图上点击开始一对点，再在另一幅图上点击对应位置完成配对；至少 **3 对**才能拟合，建议 4 对以上且点位尽量分散（残差才有统计意义，3 对时为精确解、残差恒为 0）。
3. **微调与删除**：拖动标记微调位置；右键标记或点击列表中的 ✕ 删除；`Esc` 取消未完成的半对点。任何点位变化都会**立即重算**。
4. **开启稳健模式**：勾选工具栏「**稳健模式**」，并在「**像素容差**」中填写内点允许的残差上限（参考图像素，默认 2 px，可填 0）。容差调大/调小、点位编辑或删除都会**同步重算**，无需重新打点。
5. **查看结果**：右侧面板显示六参数矩阵与 RMSE；画布与残差表区分**内点**（绿色，内点中残差最大者橙色加环）与**外点**（红色虚线、红底「外点」标签）。稳健模式的 RMSE 仅统计内点。控制点近共线（或重合）导致找不到至少三对非共线内点时，**点对会保留**，界面说明原因并**禁用导出**，调整点位或放宽容差后自动恢复。
6. **逐点留出验证**：残差表「**留出验证**」列显示每个参与点「移除后重拟合再预测」的误差（比原残差更能反映泛化能力）；验证误差最大的点以**橙色加粗**标出，状态栏与拟合面板同步给出验证 RMSE / 最大误差 / 可验证点数量。参与点不足 4 个或留出后点集近共线的点显示「无法验证」，稳健模式外点显示「不参与」；零个可验证点时汇总显示「不可用」。任何点位或参数变化都会实时重算该列。
7. **叠加预览**：底部画布将扫描图按拟合矩阵变换后与参考图叠加，用透明度滑杆对比校准效果。
8. **导出**：可下载六参数矩阵 JSON（含行主序 3×3 形式）、逐点残差 JSON 与**校准扫描图 PNG**。叠加预览与三种导出使用**同一最终矩阵**；JSON 导出文件记录模式、容差、每对点的内/外点身份及逐点留出验证结果。
9. **导出校准扫描图**：点击工具栏「**导出校准扫描图**」下载 `calibrated-scan.png`——尺寸与**参考图原始宽高**一致，**只含按最终拟合矩阵变换后的扫描图**（不含参考底图、控制点标记，也不受预览透明度影响），经典与稳健两种拟合模式均可导出。导出使用**点击那一刻**的扫描图与最终矩阵，逐像素经**逆仿射映射**回源图取样、四邻像素**双线性插值**重采样（详见下文「像素变换」），全部在浏览器本地完成。**图像缺失、拟合无效、矩阵含非有限值或线性部分行列式绝对值 ≤ 1e-12 时按钮禁用并说明原因**；点位、模式或容差任何变化后，按钮状态跟随重算结果实时更新。
10. **差异区域视图与人工复核**：在底部「**差异区域**」面板查看校准后仍与参考图不一致的位置。两图已加载且当前拟合矩阵可导出（与校准扫描图导出同一条件）时自动计算：复用校准扫描图的 RGBA 重采样结果与参考图逐像素比较，**仅统计双方 alpha 均不低于 128 的像素**，任一 RGB 通道差值的绝对值**严格大于「色差阈值」**（默认 32，可调 0~255）即标为差异；差异像素做**八邻域连通分组**，过滤像素数小于「**最小面积**」（默认 20 px，可调，0 表示不过滤）的区域，剩余区域**按面积降序**在右侧表格列出序号、像素数、边框 `(x, y, w×h)`、参考图坐标范围 `x min–max · y min–max` 与**人工复核结论/备注**，画布上以红底标出差异像素。**色差阈值、最小面积、控制点点位、拟合模式或像素容差变化后结果自动更新（去抖重算，拖动不卡顿）**；条件失效（缺图、控制点不足、共线拒绝、矩阵不可导出）或参数非法时**清空旧标记并在面板说明原因**。全部像素处理在浏览器本地完成，图像不上传服务器。
11. **人工复核操作**：
    - **选中区域**：点击差异视图画布中的**差异像素**（按像素命中其所属区域，点空白处取消选中），或直接点击右侧**表格行**；选中后区域以加粗亮蓝框标出、表格行高亮，编辑器显示该区域像素数与参考图坐标范围。
    - **标记结论**：点击「**标为「缺陷」**」或「**标为「可接受」**」，可在「**备注**」框填写说明（可先写备注再标记，也可标记后补写，失焦保存，上限 1000 字）；「**清除复核**」可将该区域恢复为未复核。表格「结论/备注」列与统计行（缺陷 / 可接受 / 未复核数量）实时更新，画布边框按结论着色：**橙框＝未复核、红框＝缺陷、绿框＝可接受**。
    - **重算后的结论继承**：色差阈值、最小面积或控制点变化触发重算时，系统保存重算前每个区域的实际差异像素，对新老区域逐像素计算 **交并比 IoU = 交集像素 / 并集像素**；**仅当 IoU ≥ 0.5 且该老区域只与这一个新区域重叠、该新区域也只与这一个老区域重叠（双方互为唯一重叠区域）时，才把结论与备注继承到新区域**。区域分裂、合并、漂移过大（IoU < 0.5）、消失后重现或编号发生变化的区域一律显示「**未复核**」——编号只反映当次按面积排序的结果，**不会按编号沿用**结论。
    - **导出**：点击「**导出复核 JSON**」下载 `diff-review.json`（结构见「导出文件格式」）。
    - **更换任一图片**（重新上传参考图/扫描图，或重新「载入示例图像」）会**清空全部控制点与复核记录**。
12. **局部套色偏移诊断**：整图仿射校准后，在底部「**局部套色偏移**」面板定位仍有局部偏移的位置。该视图的启用条件与差异视图、校准扫描图导出**完全一致**（两图已加载、拟合有效且矩阵可导出），满足后**自动计算并复用同一份校准扫描图重采样像素**（与色差阈值/最小面积参数**完全独立**，调这两个参数不会触发诊断重算）：
    - **分块与取样**：参考图均匀分成 **4×4 共 16 块**（坐标即参考图像素），每块在块内按宽高比**等距取至多 1024 个整数像素格点**（格点不重复，像素数不足 1024 的小块不会超过其像素数）。
    - **位移搜索**：对水平、垂直各 **±4 px 的整数位移**（dx、dy ∈ [−4, +4]，共 81 个候选，含 (0,0)）逐候选比较参考像素 `ref(x, y)` 与位移后的校准像素 `calibrated(x+dx, y+dy)`；**越界或任一方 alpha < 128 的像素对不可比较**；候选均差为可比较像素对的 **RGB 三通道平均绝对差**。
    - **合格门槛与选择规则**：候选的可比较点数**不足该块采样点数 20%** 时排除；在合格候选中**取均差最小者**（均差以整数绝对差和做精确分数比较，避免浮点平局误判）；**平局先取位移长度 sqrt(dx²+dy²) 较短者，长度也相同时按 dx 升序、再按 dy 升序**。
    - **展示**：画布按参考图坐标绘制 4×4 网格，各块以**箭头标出最佳位移方向**（`↖↑↗←→↙↓↘` 八个方向，屏幕坐标 y 向下；最佳位移为 0 时显示灰色圆点），并标注 `dx, dy` 与「位移前均差 → 位移后均差」；右侧表格逐块列出序号、参考图坐标范围、方向、dx/dy、位移长度、**位移前（0,0）均差**、**位移后（最佳位移）均差**与「最佳候选可比较点数 / 该块采样点数（合格候选数）」。**无合格候选的块**（采样区域空白/透明、或所有候选可比较点都不足 20%）显示「**不可判定**」并在画布上压暗；顶部统计给出可判定、检出局部偏移、不可判定的块数。
    - **重算与失效**：更换任一图片、点位增删拖动、切换拟合模式或调整像素容差使矩阵变化后，诊断**自动去抖重算**（拖动不卡顿）；条件失效（缺图、控制点不足 3 对、近共线被拒、矩阵含非有限值或行列式 ≤ 1e-12）时**清空旧诊断、表格与导出按钮并说明原因**。
    - **导出**：点击「**导出局部偏移 JSON**」下载 `local-shifts.json`（结构见「导出文件格式」）。

## 拟合模型

求解六参数仿射变换：

```
u = a·x + b·y + c
v = d·x + e·y + f        (x, y)：扫描图坐标 → (u, v)：参考图坐标
```

实现上先对坐标中心化，正规方程退化为两个 2×2 线性方程组，避免大坐标（高分辨率扫描）下的数值病态。近共线判定基于点集协方差矩阵最小/最大特征值之比（阈值 `1e-4`，见 `public/js/affine.js` 中 `COLLINEAR_RATIO`）。

稳健模式（`fitAffineRobust`）流程：

1. 按 `(i, j, k)` 字典序扫描至多 `MAX_CANDIDATES`（256）个三元组，跳过任一侧近共线/重合者；
2. 每个候选由三点求出精确仿射模型，统计残差 ≤ `tolerancePx` 的内点；
3. 以内点数量最多、次以内点平方误差和最小选择模型（平局保留固定顺序中的首个，结果可复现）；
4. 对内点重新做最小二乘拟合，并用新模型重新分类，迭代（至多 `MAX_REFINE_ITERS` 次）至内点集合不变；
5. 输出全部点的残差，但 RMSE 与 `maxResidualIndex` 只基于内点；内点不足 3 对或近共线时报错。

逐点留出验证（`leaveOneOutValidation`，两种拟合结果均附带 `validation` 字段）：

1. 参与集：经典模式为全部控制点，稳健模式为最终内点（外点 `excluded`，不参与）；
2. 参与点不足 4 个时，所有参与点直接标记 `unverifiable`（留出后不足 3 点，无法重拟合）；
3. 否则对每个参与点：移除该点，若剩余参与点任一侧近共线则该点 `unverifiable`；否则用剩余点重新最小二乘拟合，预测留出点的参考图位置，取预测误差为该点的留出误差；
4. 汇总（RMSE、最大误差、最差点）仅统计 `ok` 点；零个可验证点时汇总为 `null`（界面显示「不可用」）。

## 像素变换（导出校准扫描图）

`transformRGBA(srcData, srcW, srcH, matrix, outW, outH)`（`public/js/affine.js`，可独立调用，纯像素计算、不依赖 DOM）将源 RGBA 像素数组按拟合矩阵 `matrix`（扫描图 → 参考图）重采样到 `outW × outH` 的输出画布，规则：

1. 对每个输出像素 `(i, j)`，取其**像素中心** `(i+0.5, j+0.5)`，经**逆仿射映射**回源图连续坐标（源像素中心同样位于 `(x+0.5, y+0.5)`）；
2. 以**四邻像素做双线性插值**；**越界邻点视为透明黑** `(0,0,0,0)`；
3. **颜色先乘 alpha（预乘）再插值，输出时除以插值后的 alpha 还原**，避免透明像素串色；**alpha 为零时 RGB 归零**；
4. 各通道**四舍五入到 0~255**。

配套校验：`checkExportMatrix(m)` 要求六参数均为有限值且线性部分行列式 `|a·e − b·d| > 1e-12`（`MIN_MATRIX_DET`），否则返回中文原因；`invertMatrix(m)` 在校验通过后求逆，否则抛 `BAD_MATRIX`。页面导出按钮用 `checkExportMatrix` 决定启用/禁用并显示原因，导出时以 `transformRGBA` 逐像素计算后用 canvas 生成 PNG 下载，**像素处理全部留在浏览器本地**。

## 差异区域检测

差异视图复用校准扫描图的同一份 `transformRGBA` 重采样结果（参考图原始宽高），算法在 `public/js/affine.js` 中拆为两个可独立调用的纯像素函数（不依赖 DOM/Canvas）：

1. `buildDifferenceMask(refData, cmpData, w, h, colorThreshold = 32)`：逐像素比较参考图与校准扫描图。**仅当双方 alpha 均 ≥ `DIFF_ALPHA_MIN`（128）时该像素参与统计**；参与像素中任一 RGB 通道差值的绝对值**严格大于** `colorThreshold`（0~255）即置掩码 1。返回每像素 1 字节的掩码、参与统计像素数 `compared` 与差异像素数 `diffCount`。
2. `groupDiffRegions(mask, w, h, minArea = 20)`：以**八邻域（含对角）**迭代式泛洪（避免大图递归爆栈）把掩码像素分组；`pixelCount < minArea` 的区域被过滤（`minArea = 0` 表示不过滤）；剩余区域**按面积降序**（同面积保留扫描顺序，结果可复现）输出 `pixelCount`、闭区间坐标 `minX/minY/maxX/maxY` 及边框 `bounds {x, y, width, height}`（`width = maxX − minX + 1`），同时返回每像素区域编号标签 `labels`（`Uint32Array`，值为区域的 1 起编号，非保留区域像素含被过滤散点为 0），供画布点击命中与重算后的 IoU 匹配使用。处理时掩码会被就地清空（分组结果保留在 `labels` 中）。
3. `findDifferenceRegions(...)` 是上面两步的便捷封装，输出同样含 `labels`，另返回 `filteredCount`（被面积过滤的散点像素数）等汇总。
4. `matchDiffRegions(oldLabels, newLabels, w, h, minIou = 0.5)`：重算后以**区域实际差异像素**计算新老区域交并比。遍历两张同尺寸标签图统计每对 `(old,new)` 区域的交集像素数，`IoU = 交集 / (老区域像素 + 新区域像素 − 交集)`；仅当 **IoU ≥ `REVIEW_MATCH_MIN_IOU`（0.5）**、且**该老区域只与一个新区域重叠、该新区域也只与一个老区域重叠（双方互为唯一重叠区域）**时才配对，返回每对匹配的 `oldIndex/newIndex/intersection/union/iou` 及双方的重叠区域计数。不满足条件的新区域不返回匹配，调用方将其显示为未复核——与区域编号（按面积排序）无关。

页面侧（`public/js/app.js`）规则：

- 前置条件与「导出校准扫描图」完全一致（`exportImageReadiness` → `checkExportMatrix`）：两图已加载、拟合有效且矩阵可导出，否则清空差异画布/表格/统计并说明原因（缺图、控制点不足、近共线、非有限值、行列式 ≤ 1e-12）。
- 参考图与扫描图 RGBA 及 `transformRGBA` 重采样结果按「两图 + 矩阵六参数」缓存：**只调阈值/最小面积时不重新重采样**；图像更换、点位增删拖动、拟合模式或像素容差变化使矩阵改变后自动去抖（80 ms）重算。
- 画布在参考底图上以 55% 透明度叠加红色差异掩码，并对保留区域绘制边框与序号（序号与表格一致）：**橙框＝未复核、红框＝缺陷、绿框＝可接受，当前选中区域以加粗亮蓝框覆盖**；表格最多列出 200 行（超出提示已省略）。
- 点击画布时按 `labels[ y·w + x ]` 命中差异像素所属区域（点非区域像素取消选中），点击表格行同样选中；选中区域可标为 `defect`（缺陷）/ `acceptable`（可接受）并填写备注，结论与备注保存在以**当次区域编号**为键的复核表中。
- 每次有效重算先把上一次的 `{labels, reviews}` 作为快照，调用 `matchDiffRegions` 与新标签匹配，仅对满足 **IoU ≥ 0.5 且双方互为唯一重叠区域**的匹配继承结论与备注（选中区域也按同一匹配迁移，匹配不到则取消选中），其余新区域一律为未复核；区域在某次重算中消失（被阈值/最小面积过滤、拟合失效）后再重现，因与上一次结果无重叠而不会恢复旧结论。
- 复核记录只在**更换任一图片**（上传新参考图/扫描图或重新载入示例）时整体清空；阈值/最小面积临时输入非法导致视图清空后恢复合法值，仍会按 IoU 尝试继承。
- 色差阈值必须为 0~255 的数字、最小面积必须为不小于 0 的整数；参数非法时同样清空旧标记并说明原因，绝不展示与输入不符的旧结果。
- 全部计算在浏览器本地完成，**图像不会上传服务器**。

## 局部套色偏移诊断

整图仿射只能消除全局性变形，纸张局部伸缩、重影等仍会留下**局部**套色偏移。`analyzeLocalShifts(refData, cmpData, w, h, options?)`（`public/js/affine.js`，可独立调用，纯像素计算、不依赖 DOM/Canvas）在分块粒度上做小范围整数位移搜索，定位这些残余偏移。输入与差异检测一致：参考图 RGBA 与同尺寸的校准扫描图 RGBA（`transformRGBA` 的输出）。算法流程：

1. **分块**：参考图均匀分成 `cols × rows`（默认 `LOCAL_GRID_COLS = LOCAL_GRID_ROWS = 4`）块，分区点取 `round(k·w/cols)` / `round(k·h/rows)`（覆盖整图无空洞；图像尺寸比分块数还小时部分块宽/高为 0，这些空块直接标记不可判定且尽量靠后），行优先给出 1 起块编号与参考图像素边框。
2. **等距取样**：每块由 `sampleLayout(bw, bh, maxSamples)` 按宽高比分配 `nx × ny` 个格点，**保证 `nx·ny ≤ maxSamples`（`LOCAL_MAX_SAMPLES_PER_BLOCK = 1024`）且 `nx ≤ bw、ny ≤ bh`**（格点不重复，小块不会超过其像素数），两方向格点间距尽量等距；格点为整数像素中心等距位置四舍五入到最近像素（端点不贴边）。大图像因此至多逐块评估 1024 个采样点，计算量有界。
3. **候选评估**：对每个整数位移 `(dx, dy) ∈ [−rangePx, +rangePx]²`（`LOCAL_SHIFT_RANGE_PX = 4`，共 81 个候选），在采样格点上比较参考像素与**位移后**的校准像素 `(x+dx, y+dy)`：越界或**任一方 alpha < `DIFF_ALPHA_MIN`（128）**的像素对不计；对可比较像素对累加三通道绝对差之和 `|R|+|G|+|B|`，候选均差（RGB 平均绝对差）= 绝对差之和 /（可比较点数 × 3）。
4. **合格门槛**：候选可比较点数 `< ceil(minComparableRatio × 采样点数)`（`LOCAL_MIN_COMPARABLE_RATIO = 0.2`，即 **20%**，且不少于 1）时排除，避免仅用极少几个边缘像素下结论。
5. **选择与平局规则**：在合格候选中取均差最小者。均差比较以「整数绝对差和 / 可比较点数」做**精确分数交叉相乘**（不引入浮点平局误差）；均差相同先取**位移长度 sqrt(dx²+dy²) 较短**者，长度也相同再按 **dx 升序、dy 升序**。实现上候选预先按 `(len², dx, dy)` 排序，首个出现的最小均差候选即最终结果，结果可复现。
6. **输出**：每块返回块坐标/尺寸、`sampleCount`、位移前 `(0,0)` 的均差 `meanBefore` 与可比较点数 `comparableBefore`（即便不足门槛也保留，供展示「位移前均差」）、`decidable`、最佳 `dx/dy/shiftLengthPx/meanAfter/comparableCount` 与合格候选数 `eligibleCandidateCount`。**无合格候选时 `decidable=false`，最佳位移与位移后均差字段为 `null`**（界面显示「不可判定」）。

页面侧（`public/js/app.js`）规则：

- 前置条件与差异视图、校准扫描图导出**完全一致**（两图已加载 + 拟合有效 + `checkExportMatrix` 通过）；条件失效时清空画布/表格/统计、禁用导出并说明原因。
- **复用差异视图的同一份像素缓存** `ensureDiffCache`（参考图 RGBA + 当前矩阵的 `transformRGBA` 重采样结果，按两图与矩阵六参数缓存）：只调色差阈值/最小面积不会重采样、也不会触发局部诊断重算；图像或矩阵变化后去抖（80 ms）重算。
- 画布以参考图为底图绘制 4×4 网格与各块标注：**8 方向箭头＝最佳位移方向**（屏幕坐标 y 向下，与 `dx,dy` 的符号一致），非零位移块用**橙色**，最佳位移为 0 用灰色圆点 `●`，不可判定块整体压暗显示「不可判定」；同时标注 `dx, dy` 与「位移前均差 → 位移后均差」，左上角为块序号。右侧表格逐块列出对应字段，非零位移行橙色、不可判定行灰色。
- 局部诊断**不涉及人工复核状态**，也不随差异阈值变化；仅由图像/矩阵变化驱动，条件恢复后自动重新计算。
- 全部计算在浏览器本地完成，**图像不会上传服务器**。

## API

拟合逻辑（`public/js/affine.js`）在浏览器与 Node 间共用，服务器同时暴露接口供程序化调用：

```bash
# 经典最小二乘
curl -X POST http://localhost:3000/api/fit \
  -H 'Content-Type: application/json' \
  -d '{"src":[{"x":0,"y":0},{"x":100,"y":0},{"x":0,"y":100}],
       "dst":[{"x":15,"y":-20},{"x":117,"y":-19},{"x":14,"y":78}]}'

# 稳健模式（容差 2px）
curl -X POST http://localhost:3000/api/fit \
  -H 'Content-Type: application/json' \
  -d '{"robust":true,"tolerancePx":2,
       "src":[{"x":0,"y":0},{"x":100,"y":0},{"x":0,"y":100},{"x":500,"y":500}],
       "dst":[{"x":15,"y":-20},{"x":117,"y":-19},{"x":14,"y":78},{"x":0,"y":0}]}'
```

| 接口 | 说明 |
| --- | --- |
| `GET /api/health` | 健康检查 |
| `POST /api/fit` | 仿射拟合。请求体 `{src, dst, robust?, tolerancePx?}`，`src/dst` 为等长控制点数组（≥ 3）。成功返回 `{ok, mode, matrix, residuals, rmse, maxIndex, pointCount, inliers, validation, ...}`；稳健模式额外含 `inlierCount/outlierCount/tolerancePx/candidatesEvaluated`。参数非法 `400`，点数不足/近共线/无可用非共线三点 `422` |

`validation` 为逐点留出验证结果，页面与接口由同一份 `public/js/affine.js` 计算，输出一致：

```json
{
  "points": [{ "index": 0, "participates": true, "status": "ok", "error": 0.324 }],
  "participantCount": 5,
  "verifiableCount": 5,
  "rmse": 0.786,
  "maxError": 1.118,
  "maxIndex": 4
}
```

- 逐点 `status`：`ok`（可验证，带 `error`）/ `unverifiable`（参与点不足 4 个或留出后近共线，`error` 为 `null`）/ `excluded`（稳健模式外点，不参与）。
- 汇总仅统计可验证点；零个可验证点时 `rmse / maxError` 为 `null`、`maxIndex` 为 `-1`（不可用）。

## 导出文件格式

**affine-matrix.json**

```json
{
  "mode": "robust",
  "matrix": { "a": 1.0, "b": 0.0, "c": 0.0, "d": 0.0, "e": 1.0, "f": 0.0 },
  "matrixRowMajor": [[1, 0, 0], [0, 1, 0], [0, 0, 1]],
  "rmse": 0.123,
  "rmseScope": "inliers",
  "pointCount": 5,
  "tolerancePx": 2,
  "inlierCount": 4,
  "outlierCount": 1,
  "looValidation": { "participantCount": 4, "verifiableCount": 4, "rmse": 0.21, "maxError": 0.4, "maxIndex": 3 }
}
```

**residuals.json**：`{ mode, rmse, rmseScope, tolerancePx?, inlierCount, outlierCount, maxResidualIndex, looValidation, points: [{ id, scan, ref, residualPx, isInlier, isMaxResidual, looStatus, looErrorPx }] }`。外点 `isInlier` 为 `false`，其残差仍列出但不参与 `rmse`；`looStatus` 取值 `ok / unverifiable / excluded`（对应可验证 / 无法验证 / 外点不参与），不可验证时 `looErrorPx` 为 `null`；`looValidation` 为留出验证汇总（零个可验证点时各统计量为 `null`）。

**calibrated-scan.png**：与参考图原始宽高一致的 PNG，只含按最终拟合矩阵变换后的扫描图（无参考底图、无标记、无预览透明度）。逐像素经逆仿射映射 + 四邻双线性插值生成（规则见「像素变换」），两种拟合模式均可导出；图像缺失 / 拟合无效 / 矩阵含非有限值 / 行列式 `|a·e − b·d| ≤ 1e-12` 时禁止导出。

**diff-review.json**（差异区域人工复核，点击「导出复核 JSON」下载；坐标均为参考图像素）：

```json
{
  "description": "差异区域人工复核结果（坐标均为参考图像素；结论 defect=缺陷、acceptable=可接受、null=未复核）",
  "imageSize": { "width": 960, "height": 640 },
  "colorThreshold": 32,
  "minArea": 20,
  "diffPixelCount": 100,
  "regionCount": 1,
  "reviewedCount": 1,
  "defectCount": 1,
  "acceptableCount": 0,
  "pendingCount": 0,
  "regions": [
    {
      "index": 1,
      "pixelCount": 100,
      "bounds": { "x": 40, "y": 50, "width": 10, "height": 10 },
      "refCoordinateRange": { "minX": 40, "minY": 50, "maxX": 49, "maxY": 59 },
      "verdict": "defect",
      "note": "套色漏白，判定缺陷",
      "reviewedAt": "2026-09-28T12:00:00.000Z"
    }
  ],
  "exportedAt": "2026-09-28T12:00:01.000Z"
}
```

- `regions[]` 按当次结果的面积降序（`index` 为 1 起序号）；`bounds` 为左上角与边长，`refCoordinateRange` 为参考图坐标的闭区间范围，`pixelCount` 为区域内实际差异像素数。
- `verdict`：`"defect"`（缺陷）/ `"acceptable"`（可接受）/ `null`（未复核）；未复核时 `note` 为 `""`、`reviewedAt` 为 `null`。
- 复核结论只在**重算前后区域实际差异像素 IoU ≥ 0.5 且双方互为唯一重叠区域**时继承（见「差异区域检测」）；`index` 不保证跨重算稳定，程序化消费时应以坐标范围/像素集合为准，不应按 `index` 关联历史结论。

**local-shifts.json**（局部套色偏移分块诊断，点击「导出局部偏移 JSON」下载；坐标均为参考图像素）：

```json
{
  "description": "局部套色偏移分块诊断（参考图 4×4 分块；在 ±4 px 整数位移内比较参考像素与位移后的校准像素，仅计双方 alpha ≥ 128 的 RGB 平均绝对差，可比较点不足采样点数 20% 的候选排除；dx/dy 为校准像素相对参考像素的最佳位移，方向箭头按屏幕坐标（y 向下））",
  "imageSize": { "width": 960, "height": 640 },
  "grid": { "cols": 4, "rows": 4 },
  "maxSamplesPerBlock": 1024,
  "shiftRangePx": 4,
  "alphaMin": 128,
  "minComparableRatio": 0.2,
  "blockCount": 16,
  "decidableCount": 16,
  "shiftedCount": 1,
  "undecidableCount": 0,
  "blocks": [
    {
      "index": 1,
      "row": 0,
      "col": 0,
      "bounds": { "x": 0, "y": 0, "width": 240, "height": 160 },
      "refCoordinateRange": { "minX": 0, "minY": 0, "maxX": 239, "maxY": 159 },
      "sampleCount": 1014,
      "comparableBeforeShift": 951,
      "meanAbsoluteDiffBeforeShift": 1.0726,
      "decidable": true,
      "dx": 0,
      "dy": 2,
      "shiftLengthPx": 2,
      "direction": "↓",
      "meanAbsoluteDiffAfterShift": 1.0462,
      "comparablePointCount": 975,
      "eligibleCandidateCount": 81
    }
  ],
  "exportedAt": "2026-09-29T12:00:01.000Z"
}
```

- `blocks[]` 按**行优先**顺序（从上到下、每行从左到右）排列，`index = row·cols + col + 1`；`row/col` 均为 0 起。
- `dx/dy`：在 ±4 px 整数位移搜索中胜出的最佳位移，语义为「校准像素相对参考像素的位移」——即 `calibrated(x+dx, y+dy)` 与 `ref(x,y)` 最接近；`direction` 为与画布一致的 8 方向箭头（屏幕坐标 y 向下），`(0,0)` 时为 `●`。
- `meanAbsoluteDiffBeforeShift`：位移前 `(0,0)` 的 RGB 平均绝对差（即便不足 20% 门槛也给出；完全不可比较时为 `null`）；`meanAbsoluteDiffAfterShift`：最佳位移后的均差。均差保留 4 位小数。
- `sampleCount` 为该块等距采样点数（≤ `maxSamplesPerBlock`）；`comparablePointCount` 为最佳候选的可比较点数（双方 alpha ≥ 128 且未越界）；`eligibleCandidateCount` 为通过 20% 门槛的候选数（最多 81）。
- **`decidable=false`（不可判定）的块**：`dx/dy/shiftLengthPx/direction/meanAbsoluteDiffAfterShift/comparablePointCount` 为 `null`，`eligibleCandidateCount` 为 0；空白/透明占比过大、所有候选可比较点都不足采样点数 20% 时出现。
- 诊断只对**当前这对图像与当前拟合矩阵**有意义，图像或矩阵变化后结果自动重算，不应跨状态按 `index` 关联。

## 说明

- 更换任一图像会清空已有控制点（坐标随图像失效），并同时**清空全部差异区域人工复核记录**（结论与备注只对当前这对图像有意义）。
- 差异区域编号是当次结果按面积降序的序号，重算后可能变化；复核结论的继承完全基于区域实际差异像素的 IoU 匹配（≥ 0.5 且互为唯一重叠），不按编号沿用。
- 局部套色偏移诊断复用校准扫描图的同一份重采样像素，与差异视图参数（色差阈值、最小面积）无关；分块边界与箭头坐标均为参考图像素，`dx/dy` 表示校准像素相对参考像素的最佳位移。空白/透明区域可比较点不足采样点数 20% 时该块「不可判定」，不强行给定位移。
- 画布按图像原始分辨率渲染、CSS 自适应缩放，点击坐标按缩放比换算回图像像素，保证取点精度。
- 稳健模式只改变拟合与标识，不会删除任何点对；关闭开关即回到经典最小二乘。
